# Delegate Branding

## Name

**Delegate**

Short, sharp, and product-shaped. It implies controlled transfer of authority rather than blind autonomy.

## Tagline options

- Safe execution for autonomous agents
- Delegate actions, not trust
- Policy-first agent execution
- Let agents propose. Let policy decide.

## Brand position

Delegate should feel:
- precise
- trustworthy
- operator-friendly
- modern, not bureaucratic

Not fluffy, not fear-based, not academic.

## Visual direction

The MVP UI leans into:
- dark operator-console surfaces
- cyan accents for system clarity
- emerald / rose status signaling for allow vs deny
- large, confident typography

## Messaging principles

1. **Policy before action** — safety is a gate, not a retrospective.
2. **Determinism over vibes** — the same request should produce the same answer.
3. **Auditability by default** — trust comes from evidence.
4. **Human oversight stays intact** — Delegate narrows what agents can do autonomously.

## Judge/demo pitch

“Delegate is the missing permissions layer for AI agents. Instead of trusting the model directly, we turn actions into structured requests, run deterministic policy checks, and record a clear audit trail before anything executes.”
